Family Control

Ghar wale mobile ki apps yahan se band/kholein — bachon ki hifazat ke liye.

Pair Code Dalein

Ghar wale mobile par Family Guard app kholein — wahan bara sa 6 number wala code likha hoga. Wohi code yahan dalein. Ye sirf ek dafa karna hai; page code yaad rakh legi.

Note: Jo bhi ye code janta hai woh is page se ghar wale mobile ki apps band/khol sakta hai — code sirf ghar walon ko dein.

Safe Mode (Bachon Ke Liye)

Safe Mode ON ho to: bara YouTube band, saare browsers (Chrome waghera) band — sirf YouTube Kids chalega. Bekar aur gandi cheezon se bachon ki hifazat ke liye ise ON hi rakhein.
